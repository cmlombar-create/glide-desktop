# Glide - Desktop Schedule Manager

**Team Work In Progress** | **CSI 2999**

## Overview
Glide is a centralized, offline-first Java desktop application designed specifically for university student-athletes. It bridges the gap between scheduling an event and remembering to attend it by providing automated visual alerts and an uncluttered, distraction-free interface. 

Glide operates entirely offline with zero setup friction—requiring no user account registration, internet connectivity, or external server hosting.

## Key Features
* **100% Offline Storage:** All data is stored locally using a serverless SQLite database.
* **Automated Visual Alerts:** Background time-tracking delivers dynamic, always-on-top visual popup notifications before scheduled deadlines.
* **Strict Categorization:** Events are filtered into 8 predefined student-athlete categories (Exam, Lecture, Homework, Practice, Game, Study, Work, Personal).
* **Rapid Entry:** Create, categorize, and save a new scheduled event in 3 mouse clicks or fewer.

## Technology Stack
* **Language:** Java SE 17
* **GUI Framework:** Java Swing
* **Database:** SQLite 3 (via Xerial JDBC Driver)
* **IDE:** Apache NetBeans 18+
* **Testing:** JUnit 5
